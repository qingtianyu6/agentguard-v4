# 威胁模型及证明范围

保护对象：受 AgentGuard 网关管理的 MCP 工具调用及已登记的服务。攻击者可控制非可信文档、工具返回内容、工具描述及恶意 Agent 指令，但不能控制策略存储、可信身份凭据和网关代码。

必须由部署环境保证 Agent 不能直接连接受保护工具，且工具凭据仅由网关持有。单纯客户端插件拦截不提供不可绕过保证。

验证分层：自然语言语义由人工金标准复核；形式后端仅证明明确 IR 与有限/符号状态中的性质；运行时判断基于实际可观测事件。不可将有界模型检查标为无限状态证明，不能将候选 Recovery 视为任务完成。

明确排除：未受管的本地终端、浏览器或网络出口；外部工具自身恶意实现；可信管理员滥用；由大模型自行声称的脱敏与审批。
